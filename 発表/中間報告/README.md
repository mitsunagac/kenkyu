# 中間報告スライド

中間発表用の PowerPoint を置く場所。**発表のたびに新しい回のフォルダを作って更新する。**

## フォルダの作り方

```text
発表/中間報告/
├── README.md                ← このファイル（運用ルール）
├── 第一回/                   ← 過去回。触らない
├── 第二回 (8月5日)/           ← 今回
│   ├── 中間発表スライド.pptx              ← 本体
│   └── 中間発表スライド_変更前バックアップ.pptx  ← 更新前の控え
└── 第三回 (○月○日)/          ← 次回はここを作る
```

命名は **`第N回 (M月D日)`**。過去回のフォルダは残し、**新しい回は直前の回をフォルダごとコピーして**から中身を更新する。

## 依頼のしかた

「`発表/中間報告/第三回 (○月○日)` を作ってスライドを最新にして」と伝えれば、以下を実施する。

1. 直前の回のフォルダをコピーして新しい回のフォルダを作る
2. `中間発表スライド_変更前バックアップ.pptx` として更新前の控えを残す
3. スライドを最新の研究内容に更新する
4. **編集した箇所を「変更前 → 変更後」で一覧提示する**

## 決まりごと

| 項目 | 内容 |
| --- | --- |
| **フッター** | **「高橋福田研究室 ○月中間発表」**（○は発表月）。全スライド統一 |

| バックアップ | 更新前に `_変更前バックアップ.pptx` を必ず残す |
| 過去回 | 編集しない |

## 表の画像について

表2〜表5 は PowerPoint の表ではなく**画像**（`ppt/media/image13〜16.png`）として貼られている。
数値を更新するには画像を作り直して差し替える必要がある。

作業用スクリプトの作り方は次のとおり（`python-pptx` と `matplotlib` を使用）。

```python
# 1) matplotlib で表画像を作る（フォントは Meiryo、改善は青 #9DC3E6 / 悪化はオレンジ #FFC000）
# 2) 画像パーツの中身を差し替える
from pptx import Presentation
prs = Presentation(path)
for sl in prs.slides:
    for sh in sl.shapes:
        if sh.shape_type == 13:                      # PICTURE
            rid = sh._element.blipFill.blip.rEmbed
            ipart = sh.part.related_part(rid)
            if ipart.partname.name.endswith("image14.png"):
                ipart._blob = open("新しい表.png", "rb").read()
prs.save(path)
```

同じ画像が複数スライドで使い回されている（image15/16 は slide25 と slide26 の両方）ので、
1回差し替えれば両方に反映される。

## ★図形は削除しないこと（重要）

slide10 のように**アニメーションの重ね図**になっているスライドがある。
図形を削除すると `<p:timing>` が参照している図形ID（`spid`）が行き場を失い、
**PowerPoint がファイルを開けなくなる**（実際に一度壊した）。

古い情報を消したいときも、**図形は残してテキストだけを新しい内容に書き換える**。
重ね図の各レイヤに同じ見出しがあることがあるので、`walk()` でグループの中まで辿り、
**該当する文字列をすべて**書き換える。

```python
def walk(shapes):
    for sh in shapes:
        if sh.shape_type == 6:      # GROUP
            yield from walk(sh.shapes)
        else:
            yield sh
```

なお、アニメーション付きのスライドを静止画に書き出すと全レイヤが同時に描画されるため、
文字が重なって見える。これは書き出し時だけの現象で、実際のスライドショーでは問題ない。

## 文字数に注意

図の近くにあるテキストボックスは幅が狭い。長い文言に置き換えると折り返して図に重なる。
`例) t1 > t2` のような短いラベルは、**同じくらいの長さ**の文言に置き換えること。

## 見た目の確認方法

PowerPoint の COM 経由でスライドを画像に書き出せる。

```powershell
$ppt = New-Object -ComObject PowerPoint.Application
$pres = $ppt.Presentations.Open($path, $true, $false, $false)
$pres.Slides(10).Export("out.png", "PNG", 1400, 1050)
$pres.Close(); $ppt.Quit()
```

`Presentations.Open` が「ファイルを開けません」で失敗する場合は、
**編集でファイルを壊した可能性が高い**。バックアップから復元してやり直す。

## テキストを書き換えるときの注意

`shape.text_frame.text = "..."` で代入すると**書式（フォント・サイズ・色）が失われる**。
段落の最初のランだけを書き換え、残りのランを空文字にすると書式が保たれる。

```python
p = shape.text_frame.paragraphs[0]
p.runs[0].text = "新しい文字列"
for r in p.runs[1:]:
    r.text = ""
```

def delete_slide(prs, idx0):

## ゼロから作り直した新規案

`第二回 (8月5日)/中間発表スライド_新規案.pptx`（18枚・10分想定）。
既存デッキの**マスター/レイアウトを流用**して共通デザイン（フッター・日付・
ページ番号・文字サイズ）を保ちつつ、スライドはすべて新規に構成したもの。
生成スクリプトの要点:

- `prs.slides.add_slide(layout)` で追加 → 旧スライドをあとから全削除
- フッター/日付/ページ番号の sp は**旧スライドから XML ごと deepcopy**
  （add_slide では複製されないため）
- レイアウト既定の自動「・」は各段落に `a:buNone` を入れて無効化
  （記号は旧デッキ同様に手入力する）
- **プレースホルダの位置を一部だけ変更してはいけない**。
  `body.height = ...` だけ設定すると xfrm が部分生成され幅0（縦書き状態）になる。
  変更時は left/top/width/height の4値すべてを明示する。

## 強調図形（赤枠・マスク）の位置合わせ

旧26（一般手法との比較）の赤枠・白マスク・中かっこは**旧テーブル画像の行位置**に
合わせて置かれている。表画像を差し替えたら、行の高さ（画像高さ÷行数）から
位置を計算して `sh.top / sh.height` で合わせ直す。不要になったマスクは削除せず
**1EMU に極小化**して見えなくする（削除はファイル破損のもと）。
