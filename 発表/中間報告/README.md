# 中間報告スライド

中間発表用の PowerPoint を置く場所。**発表のたびに新しい回のフォルダを作って更新する。**

## フォルダの作り方

```text
発表/中間報告/
├── README.md                ← このファイル（運用ルール）
├── 第一回/                   ← 過去回。触らない
├── 第二回 (8月5日)/           ← 今回
│   ├── 中間発表スライド.pptx              ← 本体
│   └── 中間発表スライド_変更前バックアップ.pptx  ← 更新前の控え
└── 第三回 (○月○日)/          ← 次回はここを作る
```

命名は **`第N回 (M月D日)`**。過去回のフォルダは残し、**新しい回は直前の回をフォルダごとコピーして**から中身を更新する。

## 依頼のしかた

「`発表/中間報告/第三回 (○月○日)` を作ってスライドを最新にして」と伝えれば、以下を実施する。

1. 直前の回のフォルダをコピーして新しい回のフォルダを作る
2. `中間発表スライド_変更前バックアップ.pptx` として更新前の控えを残す
3. スライドを最新の研究内容に更新する
4. **編集した箇所を「変更前 → 変更後」で一覧提示する**

## 決まりごと

| 項目 | 内容 |
| --- | --- |
| **フッター** | **「高橋福田研究室 ○月中間発表」**（○は発表月）。全スライド統一 |
| 日付 | PowerPoint の自動更新フィールド（`datetime1`）。開いた日付が入るので編集不要 |
| バックアップ | 更新前に `_変更前バックアップ.pptx` を必ず残す |
| 過去回 | 編集しない |

## 表の画像について

表2〜表5 は PowerPoint の表ではなく**画像**（`ppt/media/image13〜16.png`）として貼られている。
数値を更新するには画像を作り直して差し替える必要がある。

作業用スクリプトの作り方は次のとおり（`python-pptx` と `matplotlib` を使用）。

```python
# 1) matplotlib で表画像を作る（フォントは Meiryo、改善は青 #9DC3E6 / 悪化はオレンジ #FFC000）
# 2) 画像パーツの中身を差し替える
from pptx import Presentation
prs = Presentation(path)
for sl in prs.slides:
    for sh in sl.shapes:
        if sh.shape_type == 13:                      # PICTURE
            rid = sh._element.blipFill.blip.rEmbed
            ipart = sh.part.related_part(rid)
            if ipart.partname.name.endswith("image14.png"):
                ipart._blob = open("新しい表.png", "rb").read()
prs.save(path)
```

同じ画像が複数スライドで使い回されている（image15/16 は slide25 と slide26 の両方）ので、
1回差し替えれば両方に反映される。

## テキストを書き換えるときの注意

`shape.text_frame.text = "..."` で代入すると**書式（フォント・サイズ・色）が失われる**。
段落の最初のランだけを書き換え、残りのランを空文字にすると書式が保たれる。

```python
p = shape.text_frame.paragraphs[0]
p.runs[0].text = "新しい文字列"
for r in p.runs[1:]:
    r.text = ""
```
